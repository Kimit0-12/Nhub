# NHub

NHub is a playful productivity app built around focus, breaks and rewards.

This repository contains its public landing page: a responsive React site with
an interactive Focus demo and a first look at Canutín's accessories and styles.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static site is generated in `dist/`, ready for Cloudflare Pages.
